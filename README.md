# gaugeschema

Gauge validation gates for schema inputs before they hit prod.

**Site:** https://theworker02.github.io/gaugeschema/

## Install / run

```bash
git clone https://github.com/theworker02/gaugeschema.git
cd gaugeschema
node src/cli.js
node --test
```
